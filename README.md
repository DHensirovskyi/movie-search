Calipso Movie Search App
A responsive and feature-rich movie discovery web application built with Next.js (App Router) and Mantine UI. This project allows users to discover, search, and save their favorite movies.

➡️ View Live Demo
https://movie-search-calipso.vercel.app/

✨ Features
Movie Discovery: Browse movies by categories like Popular, Top Rated, and Upcoming.

Dynamic Loading: "Load More" button for seamless Browse within categories.

Advanced Search: Real-time search functionality.

Detailed Pages: Dedicated pages for both movies and actors with detailed information.

Favorites System: Users can "like" movies, and their selection is saved persistently in their browser's localStorage.

Modern UX: Smooth page transitions, loading skeletons, and a full-screen preloader for an excellent user experience.

Responsive Design: A mobile-first approach ensures a great experience on all devices.

🛠️ Tech Stack
Framework: Next.js 15 (App Router)

Language: TypeScript

Styling: Mantine UI, CSS Modules

Animation: Framer Motion

State Management: React Hooks (useState, useEffect), React Context API

Data Fetching: The Movie Database (TMDB) API

Deployment: Vercel
